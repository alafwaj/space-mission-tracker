Project Reflection



I learned how to utilize Git and GitHub to manage software development projects. I learned how to create repositories, create and manage GitHub issues, organize and manage tasks, branch, commit and push to GitHub, and create and manage pull requests.

I learned how project planning makes development a lot easier because a large project can be broken into smaller sub-projects. GitHub issues allowed me to organize the work and keep track of features to be completed.

What Was Challenging

The most challenging was learning Git branching and committing. I got confused as to the reason why changes have to be staged before a commit could be made.

Pull requests and branch merging was also new to me and required practice. I learned how, with good branching and merging practices, development can be kept organized.

What Was Fun

The most fun part was developing the Space Mission Tracker. I liked developing the website and adding commits to see the website improve. Also, I learned how GitHub keeps a history of all changes made to a project and how to view project changes.

What I Would Improve

I would improve this project by creating an actual NASA web API to retrieve images of missions, Space shuttles and accomplishments. Add more search options and features to project.

I would improve the web design and make it more responsive to smaller screens and more professional.
