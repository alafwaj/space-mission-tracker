Project Reflection

What I Learned



During this project, I learned how to use Git and GitHub to manage a software project. I learned how to create a repository, create GitHub Issues, organize tasks, create branches, make commits, push changes to GitHub, and create and merge pull requests.



I also learned that project planning makes development easier because a large project can be divided into smaller tasks. GitHub Issues helped me organize the work and keep track of the features that needed to be completed.



What Was Challenging



One challenging part was learning how Git branches and commits work. At first, it was confusing to understand why changes needed to be staged before creating a commit.



Creating pull requests and merging branches was also something I had to learn. After practicing it, I understood how feature branches can be used to keep changes organized before merging them into the main project.



What Was Fun



The most fun part was creating the Space Mission Tracker and seeing the project improve after each commit. I also enjoyed creating the space-themed design and learning how GitHub keeps track of the project's history.



What I Would Improve



If I had more time, I would improve the project by connecting it to a real NASA API. I would add more space missions, images, search functionality, and interactive features.



I would also improve the website design so that it works better on mobile devices and looks more professional.
